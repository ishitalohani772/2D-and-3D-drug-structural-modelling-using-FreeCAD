# 2D-and-3D-drug-structural-modelling-using-FreeCAD
This project demonstrates the development of a 2D structural design and its corresponding 3D model using FreeCAD. The exercise focused on understanding basic CAD-based modelling workflows, dimensional control, and feature-based design.
Key Learning:

Working plane/axis selection
2D structural sketching
3D feature generation
Pad operation
Fillet operation
Radius adjustment
Maintaining dimensions
Basic 3D structural visualization

Software Used:
FreeCAD
